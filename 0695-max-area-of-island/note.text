Max Area of Island

題目概述

給 m×n 的 grid，1 是陸地 0 是水，四方向相連算同一座島。
回傳最大島嶼的面積（格數）。
Grid 題的圖是隱含的：鄰居用 r±1, c±1 算出來，不需要建 adjacency list。
本質是：走訪每座島，數格數，取最大。


解題邏輯

1. DFS 回傳版 ← 主力
dfs(r, c) 回傳「從這格延伸出去，這座島還有幾格」。
base case：出界 or (r,c) in visit or grid[r][c] == 0 → return 0
否則 visit.add((r,c))，然後
    return 1 + dfs(上) + dfs(下) + dfs(左) + dfs(右)
那個 1 是「我自己這格」，四個 dfs 回傳的是各方向延伸出去的格數。
外層雙迴圈每格叫一次：maxTotal = max(maxTotal, dfs(r, c))
參數只有 r, c —— 面積是回傳值，不是參數。

2. BFS 版（避開遞迴深度）
外層遇到未訪的陸地就開一個 queue，一邊 pop 一邊 count += 1。
關鍵：進 queue 的當下就 visit.add，不是 pop 的時候。
否則同一格會從不同鄰居被重複塞進 queue。


踩過的坑

1. 用 max 不是 sum ← 第一版就錯這個
   total = max(dfs(上), dfs(下), dfs(左), dfs(右)) 算的是「最長路徑」不是面積。
   面積要四個方向全部加起來。
   而且四個都回 0 時，max 會把累積的 total 覆寫成 0。

2. visit.remove 不能寫
   這題的 visit 是「永久已算過」，不是 Course Schedule 的 visiting（當前路徑）。
   一格屬於哪座島是永久事實，不需要撤銷。
   寫了 remove 會讓每格可以無限重走 → 指數級。
   對照 Course Schedule 筆記坑 5：兩種標記生命週期相反，這題只要永久那種。

3. total 當參數傳下去是錯的
   def dfs(r, c, total) 這個 total 不管怎麼寫都是多餘的。
   我寫過 total = (dfs(...) + dfs(...) + ...)，結果 total 被整個覆寫，
   傳下去的值從來沒進入回傳值 → 永遠回傳 0。
   觀念：參數往「下」傳，答案往「上」回，兩個方向不一樣。
   而且四個分支是各自複製一份參數，互相看不見對方數了幾格，
   所以「傳下去」在多分支遞迴根本累加不起來。
   要用往下傳的寫法只能 nonlocal 共用變數，但每座島要重置，比較囉嗦。

4. visit 不能在外層迴圈重置 ← 我原本以為要重置
   共用同一個 visit 才是對的，而且正是複雜度的來源。
   第一格展開整座島，同島的其他格之後都 O(1) 秒回。
   每次重置 → 每次都可能走遍全圖 → O((mn)²)。答案還是對，但會 TLE。

5. dfs 的工作有算進去，但總量是 mn 不是「每次 mn」
   誤解：外層 mn 次 × 每次 dfs 走 mn 格 = (mn)²
   實際：visit 讓「展開」變成全域配額，用完就沒了。
   那 mn 次外層呼叫共用同一份 mn 次展開的預算，不是各自擁有一份。
   3×3 全陸地實測：總工作 17，不是 81。
   一次 dfs 的上限就已經是整個演算法的上限。

6. 每格會被鄰居呼叫好幾次，但只展開一次
   中間那格會被上下左右四個鄰居都叫到，只有第一次真的展開。
   總呼叫 ≈ 4mn，4 是常數所以丟掉。
   同 O(V+E) 裡 E ≈ 4V 被吸收成 O(V)。

7. 遞迴深度最壞是 m×n，不是 min(m,n)
   蛇形島可以逼到全滿：走完最後一格前，前面每一格都還在堆疊上。
   m,n ≤ 50 → 最深 2500 層，超過 Python 預設上限 1000（LeetCode 有調高）。
   想避開就改 BFS。


核心句（同時解釋 Course Schedule 和這題）
visit 讓「展開」變成一種全域配額，用完就沒了。
所以不管從哪開始、呼叫幾次，總展開數永遠 ≤ m×n。


BFS 版還沒手寫過，下次補


Time:  O(m × n)   每格最多展開一次，每次發出 4 個常數呼叫
Space: O(m × n)   visit 最多裝滿 + 遞迴堆疊最深 m×n（蛇形島）
