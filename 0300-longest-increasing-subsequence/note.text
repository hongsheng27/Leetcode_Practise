300. Longest Increasing Subsequence
題目概述
給一個整數陣列，找出最長的嚴格遞增子序列長度。可以跳過元素，但要保留原本的相對順序。

解題邏輯
用 DFS + Memoization。dfs(i) 回傳「一定選 nums[i] 當第一個元素」的最長遞增子序列長度。

每個起點先設 best = 1，代表至少可以選自己。掃過右邊所有 j，只要 nums[j] > nums[i]，就用 1 + dfs(j) 更新 best。這裡的 1 是目前選的 nums[i]，dfs(j) 是從下一個選中的元素開始能接出的最長長度。

算完把 best 存進 cache[i]，下次遇到同一個起點就直接讀 cache。外層對每個 i 呼叫 dfs(i)，取所有起點的最大值。

踩過的坑
排序會改變元素的相對順序。例如 [3, 1, 2] 的答案是 2，排序後的 [1, 2, 3] 在原陣列中無法依序選出。

dfs(i) 要固定選 nums[i]。如果只比較隔壁一格，而且讓下一層可以跳過自己的起點，就可能接錯。例如 [3, 5, 1, 2]，看到 3 < 5 時想接上從 5 開始的序列，但如果那層跳過 5、回傳 [1, 2] 的長度，就會誤算成 [3, 1, 2]。

第一次計算時，cache[i] 還沒有值。先用 best = 1，再把算好的結果存入 cache。外層也要試所有起點，例如 [5, 1, 2] 的答案從 1 開始，單呼叫 dfs(0) 只會得到 1。

複雜度
O(n²) time / O(n) 額外空間，n 是陣列長度。

每個起點只展開一次，但第一次要掃過右邊所有位置，總共比較 (n - 1) + (n - 2) + … + 1 次。重複呼叫 dfs(j) 時，查 cache 平均是 O(1)。Cache 最多存 n 筆，遞迴堆疊最深也是 O(n)。
