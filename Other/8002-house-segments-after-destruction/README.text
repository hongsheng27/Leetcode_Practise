# ============================================================
# House Segments After Destruction
#
# 一個地區可以視為一條 number line。
#
# houses 中的每個整數代表一間房子所在的位置。
#
# 例如：
#
# houses = [1, 2, 3, 6, 7, 9]
#
# number line:
#
#     1  2  3     6  7     9
#     H  H  H     H  H     H
#
#
# ------------------------------------------------------------
# House Segment
# ------------------------------------------------------------
#
# 一個 house segment 是一組 maximal consecutive houses。
#
# 也就是：
#
# 如果兩間房子的座標相差 1，
# 它們就互相相鄰。
#
# 例如：
#
# [1, 2, 3]
#
# 是一個 segment。
#
# [6, 7]
#
# 是另一個 segment。
#
# [9]
#
# 自己也是一個 segment。
#
#
# 因此：
#
# houses = [1, 2, 3, 6, 7, 9]
#
# 一開始共有 3 個 segments：
#
#     [1, 2, 3]
#     [6, 7]
#     [9]
#
#
# ------------------------------------------------------------
# Queries
# ------------------------------------------------------------
#
# queries 表示房子被摧毀的順序。
#
# 每執行一個 query：
#
# 1. 移除位於 queries[i] 的房子
# 2. 計算目前剩餘多少個 house segments
# 3. 將 segment 數量加入答案
#
#
# ------------------------------------------------------------
# Example
# ------------------------------------------------------------
#
# houses  = [1, 2, 3, 6, 7, 9]
# queries = [6, 3, 7, 2, 9, 1]
#
#
# Initial:
#
#     [1, 2, 3]   [6, 7]   [9]
#
#
# destroy 6:
#
#     [1, 2, 3]   [7]   [9]
#
#     segments = 3
#
#
# destroy 3:
#
#     [1, 2]   [7]   [9]
#
#     segments = 3
#
#
# destroy 7:
#
#     [1, 2]   [9]
#
#     segments = 2
#
#
# destroy 2:
#
#     [1]   [9]
#
#     segments = 2
#
#
# destroy 9:
#
#     [1]
#
#     segments = 1
#
#
# destroy 1:
#
#     []
#
#     segments = 0
#
#
# Return:
#
#     [3, 3, 2, 2, 1, 0]
#
#
# ------------------------------------------------------------
# Guaranteed
# ------------------------------------------------------------
#
# - houses 中所有位置都不同
# - queries 中所有位置都不同
# - queries 中的每個位置都一定存在於 houses
#
#
# ------------------------------------------------------------
# Goal
# ------------------------------------------------------------
#
# 實作：
#
#     houseSegments(houses, queries)
#
# 回傳：
#
#     每次摧毀一間房子後，剩餘的 segment 數量
#
