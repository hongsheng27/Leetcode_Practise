# Minimize Expression by Adding Parentheses
#
# 給你一個字串 expression，格式固定為：
#
#     num1+num2
#
# expression 中只會有一個 '+'。
#
# 你必須：
#
# 1. 在 '+' 左邊的某個位置加入 '('
# 2. 在 '+' 右邊的某個位置加入 ')'
#
# 括號內的部分先做加法。
# 括號外如果還有數字，則視為乘數。
#
#
# Example:
#
# expression = "158+454"
#
# 可以選擇：
#
#     1(58+45)4
#
# 計算方式：
#
#     1 * (58 + 45) * 4
#     = 412
#
#
# 如果括號左邊沒有數字，左側乘數視為 1。
#
# Example:
#
#     (12+3)4
#
# 等同：
#
#     1 * (12 + 3) * 4
#
#
# 如果括號右邊沒有數字，右側乘數也視為 1。
#
# Example:
#
#     2(47+38)
#
# 等同：
#
#     2 * (47 + 38) * 1
#
#
# 回傳所有合法括號位置中，
# 可以得到的最小整數結果。
#
#
# Constraints:
#
# 3 <= len(expression) <= 21
# expression 只包含數字與一個 '+'
# '+' 左右至少各有一個 digit
# num1 與 num2 不會有 leading zero
#
#
# Target:
#
# O(m * n)
#
# m = '+' 左側數字長度
