50. Pow(x, n)
題目概述
給底數 x 和整數指數 n，計算 x 的 n 次方。n = 0 時回傳 1，n < 0 時用倒數處理。

解題邏輯
用快速冪（Exponentiation by Squaring）。recursion(base, exp, total) 表示已經累積了 total，還要乘上 base 的 exp 次方。

如果 exp 是奇數，先把平方前的 base 乘進 total。接著把 base 平方，並把 exp 用 // 2 減半。每層只呼叫一次遞迴，exp = 0 時回傳 total。

例如 2⁵ = 2 × 4²。先把一個 2 乘進 total，再把剩下的 4² 交給下一層。

踩過的坑
一開始每次只把指數往 0 移一格，所以需要 O(|n|) 次乘法。把 2¹⁰ 寫成 (2⁵)² 只省了一輪，還要對 2⁵ 繼續用同樣的方法減半，才會是 O(log |n|)。

負指數一律先取倒數，在 x 很接近 -1、指數絕對值很大時，會放大倒數的捨入誤差。這組測資原本顯示 191.06373，改成先用原始 x 算正次方、最後取倒數，就顯示預期的 191.06370。這版在負指數且 |x| ≤ 1 時最後取倒數，|x| > 1 時先取倒數，避免正次方的中間值溢位。

複雜度
O(log |n|) time / O(log |n|) 額外空間。每層只做固定次數的運算，指數每次減半。這是尾遞迴，但 Python 仍會保留呼叫堆疊。若用 while 更新相同的三個變數，額外空間是 O(1)。
