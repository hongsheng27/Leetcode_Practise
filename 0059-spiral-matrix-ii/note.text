Spiral Matrix II
===================

題目概述：
給定整數 n，建立一個 n x n 矩陣，將 1 ~ n² 按照順時針螺旋順序填入矩陣。

解題邏輯：
將目前還沒有填入的矩陣範圍，用四個 boundary 表示：

top
bottom
left
right

每一圈固定按照四個方向填入：

1. 上邊：left → right
2. 右邊：top → bottom
3. 下邊：right → left
4. 左邊：bottom → top

每完成一條邊，就代表這條邊之後不需要再處理，因此縮小對應 boundary：

走完上邊 → top += 1
走完右邊 → right -= 1
走完下邊 → bottom -= 1
走完左邊 → left += 1

持續重複，直到：

top > bottom
或
left > right

核心技巧：

不要把 Spiral Matrix 想成：


「現在人在(row, col)，下一步要往哪？」


而是拆成：


上 → 右 ↓ 下 ← 左 ↑


一次處理完整的一條邊，
再把 boundary 往內縮一圈。

另一個重要觀念：

先決定 Matrix 的 traversal（怎麼走），
再決定走到每一格時要做什麼。

這題每走到一格就是：

填入目前的 num
num += 1

因此同樣的 traversal 未來也可以拿來做讀取、排序、修改等 Matrix 題。

踩過的坑：

一開始嘗試直接利用 n 推算每一條邊應該填入的數字，例如依照位置計算某格的 value。

最外圈就容易出現 off-by-one，而且進入內圈後，起始數字與邊長都已經改變，公式會越來越複雜。

更簡單的方式是只維護：

num = 1

每走到一格就填入 num，再 num += 1。

一開始使用 row / col 一格一格移動，並用 start 判斷是否繞回左上角。

這個方法可以做，也成功 AC，但需要同時維護：

row, col
top, bottom, left, right
start

狀態太多，容易卡在「現在在哪裡、下一步往哪」的判斷。

改成「一次走完整條邊」後，不需要額外維護方向或 start。

在自己模擬一格一格走時，左邊往上的條件一開始寫得太嚴格，導致走到左下角時無法繼續往上。

Matrix traversal 的 boundary condition 很容易出現 <、<= 的錯誤，因此要特別注意 corner 是否有被包含或重複處理。

Python 反方向 range() 要注意 stop 不包含：

如果要從 right 一路走到 left：

range(right, left - 1, -1)

因為直接寫到 left 會漏掉 left 本身。

複雜度：
時間複雜度：O(n²)
矩陣共有 n² 個位置，每個位置剛好填入一次。

空間複雜度：O(n²)
需要建立最後回傳的 n x n matrix。

若不計算輸出矩陣本身，額外空間為 O(1)。
