1331. Rank Transform of an Array
題目概述：
把陣列中的每個值換成從 1 開始的排名，相同值拿相同排名，輸出維持原本的順序。

解題邏輯：
一個值的 rank 等於「比它小的不同值個數 + 1」。

先用 sorted(set(arr)) 取得去重後、由小到大的值。遍歷排序結果，把第 i 個值的 rank 設成 i + 1，存進 rankMap。最後按原陣列的順序查 rankMap，將每個排名加入 res。

例如 [100, 10, 100] 去重排序後是 [10, 100]，所以 10 排第 1、100 排第 2，最後得到 [2, 1, 2]。

踩過的坑：
原本看到 n ≤ 10⁵ 才放心用排序。可以分兩步想：題目要依「不同值的大小順序」分配 rank，所以先想到去重和排序。再用 n ≤ 10⁵ 確認 O(n log n) 的時間可以接受。

複雜度：
O(n + u log u) time / O(u) 額外空間，回傳陣列另計。

n 是陣列長度，u 是不同值的數量。去重和最後查表各掃一次原陣列，排序只處理 u 個不同值。雜湊操作以平均 O(1) 計算。
