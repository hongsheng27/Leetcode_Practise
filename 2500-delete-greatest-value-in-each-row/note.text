2500. Delete Greatest Value in Each Row
題目概述
每輪從矩陣的每一列刪掉最大值，再把這輪刪掉的數字中最大的那個加進答案，直到矩陣清空。

解題邏輯
先把每列由小到大排序，將排序後的副本存進 sortGrid。每輪從每列尾端 pop() 一次，就會取出該列目前最大的值。用 maxValue 記錄這輪取出的最大值，掃完所有列後加進 res。每列有 n 個元素，所以總共做 n 輪。

踩過的坑
確認時間複雜度時，要把排序和取值分開算。每列只有一個元素時，仍要掃完 m 列，所以 O(mn log n + mn) 也涵蓋 n = 1 的情況。

複雜度
O(mn log n + mn) time / O(mn) 額外空間，m 是列數，n 是每列的元素數量。

m 列各自排序，最壞花 O(mn log n)。尾端 pop() 攤銷 O(1)，n 輪各處理 m 列，合計 O(mn)。當 n ≥ 2 時，總時間可簡寫成 O(mn log n)。sortGrid 儲存每列的排序副本，共 mn 個元素。
