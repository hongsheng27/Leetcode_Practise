**997. Find the Town Judge**

**題目概述：**  
有 `n` 個人和一組 `trust[a, b]`，代表 `a` trust `b`。找出 Town Judge：所有其他人都 trust 他，但他不 trust 任何人；不存在則回傳 `-1`。

**解題邏輯：**  
把 `trust[a, b]` 看成 directed edge：

```text
a → b
```

Judge 必須同時滿足兩個 property：

```text
indegree = n - 1
outdegree = 0
```

因此 traverse `trust`：

```python
outdegree[a] += 1
indegree[b] += 1
```

最後 traverse `1 ~ n`，找到同時符合：

```python
indegree[person] == n - 1
outdegree[person] == 0
```

的人就 return；沒有則 return `-1`。

也可以用單一 `score` 簡化：

```text
trust 別人 → score - 1
被別人 trust → score + 1
```

Judge 不 trust 任何人、又被 `n - 1` 個人 trust，因此：

```text
score[judge] = n - 1
```

---

**踩過的坑：**

一開始把「所有人都 trust judge」理解成：

```text
trust 裡所有 t[1] 都應該是同一個 judge
```

這不成立，因為其他非 judge 的人仍然可以互相 trust。

例如：

```text
1 → 3
2 → 3
1 → 2
```

`3` 還是 judge，雖然不是所有 edge 都指向 `3`。

這題應先問答案的 property，而不是先設計 set / remove 的流程：

```text
所有人 trust judge
→ indegree = n - 1

judge 不 trust 任何人
→ outdegree = 0
```

另外曾寫：

```python
for other, judge in trust:
```

導致原本代表 candidate 的 `judge` 被 loop variable 覆蓋。

應避免同一個變數名稱代表不同 state，例如改成：

```python
for person, trusted_person in trust:
```

---

**複雜度：**

假設：

```text
T = len(trust)
```

建立 degree：

```text
O(T)
```

再檢查 `n` 個人：

```text
O(n)
```

所以：

```text
Time: O(n + T)
Space: O(n)
```

**Pattern：**

```text
Directed Graph + Indegree / Outdegree Counting

先問：
1. 一筆 input 代表什麼？
   trust[a, b] = a → b

2. 答案需要滿足什麼 property？
   indegree = n - 1
   outdegree = 0
```
