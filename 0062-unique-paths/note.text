62. Unique Paths

題目概述：

給一個 m x n grid，robot 從左上角出發，每次只能往右或往下，計算走到右下角總共有幾條不同路徑。

解題邏輯：

使用 2D DP。

定義：

dp[r][c] = 從起點走到 (r, c) 的路徑數。

第一列只能一直往右走，第一欄只能一直往下走，所以：

dp[r][0] = 1
dp[0][c] = 1

其他格子只能從上方或左方走進來：

dp[r][c] = dp[r - 1][c] + dp[r][c - 1]

最後答案為：

dp[m - 1][n - 1]

踩過的坑：

1. 一開始用純 DFS 枚舉所有路徑會 TLE。
   每一步都有往右、往下兩個選擇，會重複計算大量相同的 (r, c) state。實際上只有 m * n 個不同 state，所以應該使用 memoization 或 DP。

2. 2D DP 和 1D DP 的差別主要看 state。
   這題需要同時知道 row 和 column 才能描述目前位置，所以 state 是 (r, c)，本質上是 2D DP。

3. DP 不一定要倒著寫。
   如果定義 dp[r][c] 為「從起點走到目前位置的路徑數」，依賴上方和左方，所以從左上往右下計算。
   如果定義為「從目前位置走到終點的路徑數」，依賴下方和右方，就要從右下往左上計算。

4. Memoization 可以用 dict，也可以用 2D array。
   這題的 state 是完整且規則的 m x n grid，所以用 memo[r][c] 的 2D array 通常更自然；dict 也可以，只是比較適合不規則或 sparse state。

複雜度：

O(m * n) time / O(m * n) space
