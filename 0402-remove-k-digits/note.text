**402. Remove K Digits**

**題目概述：**  
給一個數字字串 `num` 和整數 `k`，刪掉剛好 `k` 個 digit，保持剩餘 digit 原本順序不變，使最後得到的數字最小。

**解題邏輯：**  
使用 **Greedy + Monotonic Increasing Stack**。

核心想法不是「刪掉最大的 digit」，而是：

```text
盡可能讓越左邊的 digit 越小
```

因為高位數比低位數更重要。

從左到右掃每個 `digit`。

如果目前：

```python
stack[-1] > digit
```

而且還有刪除額度：

```python
k > 0
```

代表前面的較大 digit 擋住了現在較小的 digit，因此應該把前面的 digit 刪掉：

```python
while stack and k > 0 and stack[-1] > digit:
    stack.pop()
    k -= 1
```

再把目前 digit 放進 stack：

```python
stack.append(digit)
```

這會讓 stack 儘量維持 non-decreasing。

例如：

```text
1432219
```

看到 `3`：

```text
1 4
  ↑
4 > 3
```

刪掉 `4`，讓 `3` 往前：

```text
13...
```

看到 `2`：

```text
1 3
  ↑
3 > 2
```

再刪掉 `3`：

```text
12...
```

如果全部掃完後 `k` 還大於 0，代表剩下的數字已經是 non-decreasing：

```text
123456
```

此時沒有更小的 digit 可以往前移，因此剩餘的 digit 要從尾巴刪：

```python
while k > 0:
    stack.pop()
    k -= 1
```

最後把 stack 轉成字串，並移除 leading zeros：

```python
res = "".join(stack).lstrip("0")
```

如果全部都是 `0`，`lstrip("0")` 會得到空字串，所以：

```python
return res if res else "0"
```

---

**踩過的坑：**

一開始想先找 `0` 或用 heap 找最大的 digit，但這題不是看全域最大的數，而是看：

```text
刪掉哪個 digit 可以讓更小的 digit 往更高位移
```

不能直接想「後面的 `9` 比較大，所以先刪 `9`」。

例如：

```text
1432999
k = 3
```

刪後面的 `9` 可能得到：

```text
1432
```

但優先刪前面擋住較小數字的 `4`、`3`：

```text
1299
```

而：

```text
1299 < 1432
```

因為比較數字時，是從左往右第一個不同的位置決定大小。

---

不是一定保留原本的第一位。

例如：

```text
4321
k = 2
```

第一位最多只能從前 `k + 1 = 3` 個 digit 中選：

```text
4 3 2
```

最小是 `2`。

不能選最後的 `1`，因為要讓 `1` 成為第一位，需要先刪掉：

```text
4, 3, 2
```

共 3 次，但只有 `k = 2`。

Monotonic stack 會依序：

```text
4 → 看到 3，刪 4
3 → 看到 2，刪 3
```

最後讓 `2` 成為第一位。

---

`lstrip("0")` 的意思：

```text
l = left
strip = remove
```

所以：

```python
"00200".lstrip("0")
```

得到：

```text
"200"
```

LeetCode Python 可以直接使用，不需要手動寫 while loop 去除 leading zeros。

---

**複雜度：**

每個 digit：

```text
最多 push 一次
最多 pop 一次
```

因此：

```text
Time: O(n)
Space: O(n)
```

---

**Pattern：**

```text
Greedy + Monotonic Increasing Stack
```

看到：

```text
刪除 k 個元素
保持原本順序
讓結果最小
```

可以優先想到：

```text
遇到更小的 current
→ 把前面較大的元素 pop 掉
```
