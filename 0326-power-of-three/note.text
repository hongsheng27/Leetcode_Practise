**326. Power of Three**

**題目概述：**  
給整數 `n`，判斷它是否為 3 的次方，例如 `1, 3, 9, 27...`。

**解題邏輯：**  
Power of Three 的 property：

```text
1. n > 0
2. 只要 n > 1，就必須可以被 3 整除
3. 一直除以 3，最後必須剛好變成 1
```

因此先排除：

```python
if n <= 0:
    return False
```

接著當 `n > 1` 時：

```python
if n % 3 != 0:
    return False
```

如果可以整除，就繼續：

```python
n //= 3
```

最後檢查：

```python
return n == 1
```

例如：

```text
27
→ 9
→ 3
→ 1
→ True
```

但：

```text
45
→ 15
→ 5

5 不能被 3 整除
→ False
```

另外：

```text
1 = 3^0
```

所以 `1` 本身也是 Power of Three。

**踩過的坑：**  
一開始把 property 想成：

```text
3 的倍數 + 最後除到 1
```

但單純是 3 的倍數不夠。

例如：

```text
6
```

雖然是 3 的倍數，但不是 3 的次方。

更精確的 property 是：

```text
n > 0，
而且每一步只要 n > 1 都必須可以被 3 整除，
最後剛好變成 1。
```

原本也使用：

```python
while abs(n // 3) >= 1:
```

但其實不需要 `abs()`。

因為 Power of Three 一定是正數，所以先用：

```python
if n <= 0:
    return False
```

之後直接：

```python
while n > 1:
```

會更清楚。

**複雜度：**  
每次都把 `n` 除以 3：

```text
n
→ n / 3
→ n / 9
→ ...
→ 1
```

因此：

```text
Time: O(log₃ n) = O(log n)
Space: O(1)
```
