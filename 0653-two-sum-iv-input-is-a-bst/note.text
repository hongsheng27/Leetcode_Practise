Two Sum IV - Input is a BST

題目概述：
給一棵 BST 和 k，判斷樹裡是否存在兩個不同的節點，值加起來等於 k。本質就是 Two Sum，只是資料放在樹上。

解題邏輯：
用 DFS 走訪整棵樹（順序不限），一邊走一邊用 set 記錄看過的值。

每到一個節點：
先查 k - node.val 在不在 seen，在就 return True。
再把 node.val 加進 seen。
然後往左右子樹找：dfs(node.left) or dfs(node.right)。

另一種用到 BST 性質的解法：
inorder 走訪得到排序好的 list，再用左右雙指標：
sum < k 左指標右移，sum > k 右指標左移，sum == k 就 return True。

踩過的坑：
一開始先走一遍，把所有節點的補數收集進 dict，再走第二遍去查。結果每個節點也會查到自己的補數，k = 10 時 5 會配到自己，只好用 += 2 if 2 * (k - node.val) == k else 1 計數來排除，卡很久又難讀。
根本原因是查和加入的順序反了。改成一次走訪、先查再加入，查的時候自己還不在 set 裡，就不可能配到自己，特例自然消失。

會用兩次走訪是跟 1214. Two Sum BSTs 搞混了。判斷方式：
兩個數來自同一個集合（1. Two Sum、653）=> 一次走訪，先查、再加入
兩個數來自不同集合（1214，兩棵樹各挑一個）=> 兩次走訪，A 建 set、B 去查，不會有自己配自己的問題
寫之前先問：這兩個數會不會是同一個元素？

複雜度：
O(n) time / O(n) space（set 最多存 n 個值，遞迴深度 O(h)）
