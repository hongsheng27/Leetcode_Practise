Climbing Stairs

題目概述：
每次可以爬 1 階或 2 階，問爬到第 n 階共有幾種不同走法。

解題邏輯：
定義 dp[i] = 到第 i 階的方法數。

要到第 i 階，最後一步只可能：

從 i - 1 走 1 步
從 i - 2 走 2 步

所以 transition：
dp[i] = dp[i - 1] + dp[i - 2]

Base case：
dp[1] = 1
dp[2] = 2

因為 dp[i] 只依賴前兩個 state，所以不需要存完整 dp array，只需要保留：
prev2 = dp[i - 2]
prev1 = dp[i - 1]

每一輪：
cur = prev2 + prev1
prev2 = prev1
prev1 = cur

這就是 Rolling DP / Space Optimization。

踩過的坑：

n <= 2 要先直接 return n。
更新順序不能錯，要先算 cur，再更新 prev2 和 prev1。
如果只用兩個變數或兩格 array，已經不是完整 DP table，而是 Rolling DP。
dp[i] 的定義要先想清楚，這題是「到第 i 階的方法數」。

複雜度：
Time: O(n)
Space: O(1)

核心記憶：
dp[i] = dp[i - 1] + dp[i - 2]

因為到第 i 階，只能從前 1 階或前 2 階走過來。

題型：
1D DP / Fibonacci Pattern / Rolling DP
