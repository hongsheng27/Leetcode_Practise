**836. Rectangle Overlap**

**題目概述：**  
給兩個 axis-aligned rectangles `rec1`、`rec2`，每個格式為 `[x1, y1, x2, y2]`，判斷兩個長方形是否有正面積的重疊；只有碰到邊或角不算 overlap。

**解題邏輯：**  
把每個 rectangle 拆成：

```text
x 軸 interval
+
y 軸 interval
```

例如：

```text
rec = [x1, y1, x2, y2]

x interval = [x1, x2]
y interval = [y1, y2]
```

兩個 1D interval：

```text
[start1, end1]
[start2, end2]
```

要有真正 overlap，必須滿足：

```text
較晚的 start < 較早的 end
```

也就是：

```python
max(start1, start2) < min(end1, end2)
```

因此 x 軸：

```python
isXOverlap = max(rec1[0], rec2[0]) < min(rec1[2], rec2[2])
```

y 軸：

```python
isYOverlap = max(rec1[1], rec2[1]) < min(rec1[3], rec2[3])
```

Rectangle 要有正面積 overlap，x 和 y 兩個方向都必須重疊：

```python
return isXOverlap and isYOverlap
```

---

**踩過的坑：**

一開始想先判斷哪個 rectangle 比較大，再檢查小 rectangle 的 corner 是否落在大 rectangle 裡。

這個方法不成立，因為兩個 rectangle 可能像十字交叉：

```text
      ┌──┐
 ┌────┼──┼────┐
 │    │  │    │
 └────┼──┼────┘
      └──┘
```

兩者明明有 overlap，但不一定有任何 corner 落在另一個 rectangle 裡。

另外，面積比較大也不代表它一定包住另一個 rectangle。

這題應該先把 2D 問題拆成：

```text
x interval 是否 overlap
y interval 是否 overlap
```

---

不理解為什麼 interval overlap 是：

```python
max(start1, start2) < min(end1, end2)
```

因為：

```text
overlap start = 比較晚開始的位置
overlap end   = 比較早結束的位置
```

只要：

```text
overlap start < overlap end
```

中間就真的存在一段正長度的 overlap。

例如：

```text
A = [0, 2]
B = [1, 3]
```

則：

```text
max(0, 1) = 1
min(2, 3) = 2

1 < 2
```

所以有 overlap。

如果只是碰到邊：

```text
A = [0, 1]
B = [1, 2]
```

則：

```text
max(0, 1) = 1
min(1, 2) = 1

1 < 1  # False
```

因此一定要用 `<`，不能用 `<=`。

---

**複雜度：**

只做固定次數比較：

```text
Time: O(1)
Space: O(1)
```

**Pattern：**

```text
2D Rectangle Overlap
→ 拆成兩個 1D Interval Overlap

Interval overlap:
max(start1, start2) < min(end1, end2)
```
