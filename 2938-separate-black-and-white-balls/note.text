2938. Separate Black and White Balls

題目概述：
給一個 binary string `s`，其中 `0` 和 `1` 代表兩種球。每一步只能交換相鄰的 `"10"` → `"01"`，目標是讓所有 `0` 在左邊、所有 `1` 在右邊，求最少需要幾步。

解題邏輯：
這題本質上是在計算 inversion。

每當看到一個 `0`，它最後都必須跨過它前面所有的 `1`。

所以只需要維護：

```text
count = 到目前為止看過多少個 1
```

掃描字串：

```text
如果 c == "1"
→ count += 1
```

如果遇到：

```text
c == "0"
```

這個 `0` 前面有 `count` 個 `1`，代表它需要和這些 `1` 各做一次 adjacent swap。

所以：

```text
res += count
```

例如：

```text
s = "1100"
```

掃描：

```text
第一個 1：
count = 1

第二個 1：
count = 2

第一個 0：
前面有 2 個 1
res += 2

第二個 0：
前面有 2 個 1
res += 2
```

最後：

```text
res = 4
```

可以理解成共有 4 組 inversion：

```text
1 在 0 前面
```

每一組 inversion 最終都需要一次 adjacent swap。

與 Sort 的關係：
這題其實可以用 Bubble Sort 模擬。

遇到：

```text
10
```

就交換成：

```text
01
```

每交換一次：

```text
res += 1
```

例如：

```text
1100
→ 1010
→ 1001
→ 0101
→ 0011
```

總共 4 次。

Bubble Sort 中：

```text
j
= 每一輪從左到右比較相鄰 pair
```

而：

```text
i
= 控制整個 array 要重新掃幾輪
```

一輪 `j` 不一定能排序完成，所以需要多輪。

Bubble Sort 為什麼最多跑 `n - 1` 輪就一定完成：

```text
每完整掃一輪，
至少會有一個元素被推到最終正確位置。
```

例如一般 ascending Bubble Sort：

```text
[5,1,4,2]
```

第一輪後最大的 `5` 一定被推到最右邊。

因此：

```text
第 1 輪 → 至少 1 個位置確定
第 2 輪 → 再確定 1 個位置
...
最多 n - 1 輪完成
```

這題的 `"10" → "01"` 也是同樣概念，只是 `1` 不斷被往右推。

踩過的坑：
一開始想用 two pointers 找前面的 `1` 和後面的 `0` 直接交換。

但題目的一個 step 只能做：

```text
adjacent
```
