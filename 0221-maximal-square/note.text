221. Maximal Square

題目概述：
給一個只包含 `"0"` 和 `"1"` 的 matrix，找出全部由 `"1"` 組成的最大正方形，回傳它的面積。

解題邏輯：
使用 2D DP。

定義：

```text
dp[r][c] = 以 (r, c) 這格作為右下角時，
           能形成的最大正方形邊長
```

如果 `matrix[r][c] == "0"`：

```text
dp[r][c] = 0
```

如果 `matrix[r][c] == "1"`，要看三個位置：

```text
左上   上
  ↖   ↑
    X
    ← 左
```

因此：

```text
dp[r][c]
= 1 + min(
    上,
    左,
    左上
)
```

也就是：

```text
dp[r][c]
= 1 + min(
    dp[r-1][c],
    dp[r][c-1],
    dp[r-1][c-1]
)
```

之所以取 `min`，是因為正方形必須三個方向都能支撐；能擴大的大小會被最弱的方向限制。

例如：

```text
上   = 3
左   = 3
左上 = 1
```

目前這格最多只能形成：

```text
1 + min(3, 3, 1)
= 2
```

最後記錄最大邊長 `maxSide`，答案是：

```text
maxSide * maxSide
```

可以多開一圈 padding：

```text
dp 大小 = (ROWS + 1) x (COLS + 1)
```

讓最上方、最左方預設為 0，這樣不需要另外初始化第一 row / 第一 col。

踩過的坑：
一開始看到 matrix 容易想到 DFS / BFS，但這題不是在找 connected component，而是在找「完整幾何形狀」。

真正難點不是 recurrence，而是想到：

```text
dp[r][c]
= 以這格為右下角的最大正方形邊長
```

如果沒有先定義這個 state，很難直接想到：

```text
1 + min(上, 左, 左上)
```

這題屬於另一種 2D DP pattern：

```text
不是「怎麼走到這格」
而是「以這格作為結尾，可以形成多大的結構」
```

複雜度：
O(ROWS * COLS) time / O(ROWS * COLS) space
