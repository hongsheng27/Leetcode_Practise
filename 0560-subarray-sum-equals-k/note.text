560. Subarray Sum Equals K
題目概述

給一個整數陣列 nums 和整數 k。

要找有多少個連續 subarray 的總和等於 k。

這題本質是：

Prefix Sum + HashMap
解題邏輯
1. 先想到 Prefix Sum

如果目前走到某個位置，累積總和是：

currentSum

我們希望找到一段 subarray 的 sum 是 k。

假設這段 subarray 前面的累積總和是：

oldPrefix

那就會有：

currentSum - oldPrefix = k

移項：

oldPrefix = currentSum - k

所以真正要問的是：

我目前的 prefix sum 是 currentSum

前面有沒有出現過：
currentSum - k？
2. 為什麼用 HashMap

我們需要快速知道：

某個 prefix sum
之前出現過幾次

所以建立：

freq = {0: 1}

HashMap 的意思是：

prefix sum -> 出現次數

例如：

{
    0: 1,
    1: 2,
    3: 1
}

代表 prefix sum 1 曾經出現兩次。

3. 每走到一個數字

先更新目前的 prefix sum：

prefixSum += num

然後算：

prefixSum - k

如果這個值以前出現過：

res += freq[prefixSum - k]

代表這些位置都可以當作 subarray 的起點。

最後再把目前的 prefix sum 記進 HashMap：

freq[prefixSum] = freq.get(prefixSum, 0) + 1
小例子
nums = [1, 1, 1]
k = 2

一開始：

freq = {0: 1}
prefixSum = 0

第一個 1：

prefixSum = 1

需要找：
1 - 2 = -1

沒有

把 1 存起來。

第二個 1：

prefixSum = 2

需要找：
2 - 2 = 0

0 出現過一次。

代表：

從陣列開頭到現在
sum = 2

所以答案 +1。

第三個 1：

prefixSum = 3

需要找：
3 - 2 = 1

1 以前出現過一次。

所以又找到一個 subarray：

[1, 1]

最後答案：

2
核心概念

最重要只記這段：

想找 subarray sum = k

currentPrefix - oldPrefix = k

所以：

oldPrefix = currentPrefix - k

因此：

走到 currentPrefix
↓
查 HashMap 裡有幾個 currentPrefix - k
↓
那些都是合法 subarray
為什麼一開始是 {0: 1}
freq = {0: 1}

代表：

還沒看任何元素之前
prefix sum = 0

這是為了處理「subarray 從 index 0 開始」的情況。

例如：

nums = [1, 1]
k = 2

走到第二個 1：

prefixSum = 2

2 - 2 = 0

所以需要事先存在這個 0。

為什麼不能用 set

因為同一個 prefix sum 可能出現很多次。

每出現一次，都可能代表一個不同的 subarray 起點。

所以不是只問：

有沒有出現？

而是：

出現過幾次？

因此：

Set ❌
HashMap frequency ✅
Complexity
Time: O(n)

Space: O(n)

每個元素只走一次。

每次 HashMap lookup 平均是 O(1)。
