779. K-th Symbol in Grammar
題目概述
第 1 列是 0，每往下一列就把 0 展開成 01、把 1 展開成 10。求第 n 列的第 k 格，列和位置都從 1 開始算。

解題邏輯
每個父節點固定產生兩格，所以可以從目標位置反推父節點。recursion(row, col) 回傳第 row 列第 col 格的值。第 1 列直接回傳 0。

先遞迴取得上一列第 (col + 1) // 2 格的值。回程時，col 是奇數代表左孩子，保留父值。col 是偶數代表右孩子，用 1 - parent 翻轉。

例如第 4 列第 6 格，往上依序找第 3 列第 3 格、第 2 列第 2 格、第 1 列第 1 格。從 0 回傳後，依序翻轉、保留、翻轉，最後得到 0。

踩過的坑
一開始照規則生成整列，但第 n 列有 2^(n - 1) 格。題目只問一格，可以沿著它的父節點一路往上找。遇到每個來源固定產生相同數量的位置時，可以用整除找來源、用餘數判斷是來源產生的第幾格。

切換 0-index 時，父位置和奇偶規則要一起改。入口用 k - 1，父位置改成 col // 2，偶數保留父值、奇數翻轉。

複雜度
O(n) time / O(n) 額外空間。每層只找一個父節點，共走 n 層。回程還要根據當層的 col 決定是否翻轉，所以這版是非尾遞迴。
