1214. Two Sum BSTs
題目概述：
給兩棵 BST 和一個 target，判斷能否從兩棵樹各選一個節點，使它們的值相加等於 target。

解題邏輯：
用兩趟 DFS 和一個 set。

第一趟走 root1，把每個節點的補數 target - node.val 加入 want。左子樹回傳整個過程共用的 set，再把它傳給右子樹，最後回傳收集完成的 want。

第二趟走 root2，檢查 node.val 是否在 want 裡。找到就回傳 True，否則用 or 搜尋左右子樹。整棵樹都沒找到就回傳 False。

踩過的坑：
第一次把兩棵樹放在同一個 DFS 裡走，要同時處理兩邊的 None，還要追蹤 want1、want2 各自給哪棵樹查，花了較久時間 debug。合在一起可以減少部分函式呼叫，但兩棵樹的節點仍各要處理，最壞時間一樣。面試用兩趟 DFS 比較容易寫和檢查。

收集補數時曾用 return left | right。左右子樹共用同一個 set，走完後補數已經加進去了。每層用 | 會建立新 set，第一棵樹的遍歷最壞會變成 O(m²)。直接回傳同一個 set 的參考，每次回傳是 O(1)。

複雜度：
O(m + n) time / O(m + max(h1, h2)) space。

m、n 是兩棵樹的節點數，h1、h2 是各自的高度。每個節點最多走一次，set 插入與查詢平均 O(1)。want 最多存 m 個補數，兩趟 DFS 依序執行，所以堆疊空間只取兩棵樹中較高的那個。
