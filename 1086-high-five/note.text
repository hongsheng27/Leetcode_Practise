High Five

題目概述：
給一堆 [學生 id, 分數]，算出每個學生最高 5 個分數的平均（整數除法），依 id 由小到大回傳。每個學生保證至少有 5 個分數。本質是對每個學生做 Top K。

解題邏輯：
用 hashmap 存 {id: min-heap}，每個學生的 heap 大小維持在 5。

每讀到一個分數：
push 進該學生的 heap。
heap 超過 5 個就 pop，彈掉的是目前最小的分數。
最後 heap 裡剩下的就是最高的 5 個分數。

要留最大的 K 個，用大小為 K 的 min-heap：heap 頂端永遠是前 K 名裡最小的那個，也就是最該被淘汰的。

最後依 id 排序，每個學生算 sum(scores) // 5。

另一種做法：把 items 依分數由大到小排序，每個學生收前 5 個，好寫但 O(n log n)。面試用 heap 版，能帶出 Top K 的觀念。

踩過的坑：
無，一次寫對。

複雜度：
O(n + k log k) time / O(k) space（n 是 items 數量，k 是學生人數；每次 heap 操作 O(log 5) = O(1)，每個學生最多存 5 個分數）
