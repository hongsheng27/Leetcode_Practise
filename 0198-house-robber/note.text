House Robber

題目概述：
給一排房子，每間房有不同金額，不能偷相鄰的房子，求最多可以偷多少錢。

解題邏輯：
定義：

dp[i] = 考慮到第 i 間房時，可以偷到的最大金額

到第 i 間房有兩個選擇：

不偷這間
→ dp[i - 1]
偷這間
→ nums[i] + dp[i - 2]

所以 transition：

dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])

Base case：

dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])

因為每個 state 只依賴前兩個 state，所以可以做 Rolling DP。

Rolling DP：

prev2 = 前前一個最佳答案
prev1 = 前一個最佳答案

每一輪：

cur = max(prev2 + num, prev1)

然後更新：

prev2 = prev1
prev1 = cur

也可以初始化成：

prev2 = 0
prev1 = 0

原因是還沒開始處理任何房子時，能偷到的最大金額就是 0。

這種寫法等於讓同一條 transition 從第一間房開始自己算出 base case。

踩過的坑：

偷第 i 間時不能加 dp[i - 1]，因為相鄰房不能一起偷。
max 比較的是「偷這間」和「不偷這間」。
[0, 0] 不是題目原本的 dp state，而是 Rolling DP 的初始狀態，代表還沒處理任何房子時最佳收益為 0。
如果覺得 [0,0] 不直覺，面試可以先用 nums[0]、max(nums[0], nums[1]) 的版本。

複雜度：
Time: O(n)
Space: O(1)
