Set Matrix Zeroes

題目概述：
給一個 m x n 矩陣，只要某格是 0，就把它所在的整列和整欄都設成 0，必須 in-place 修改。最佳解用 O(1) 額外空間：拿第 0 列和第 0 欄當標記區，再多一個 rowZero 變數。

解題邏輯：
用第 0 列記「哪些欄要清」，第 0 欄記「哪些列要清」。
(0,0) 同時屬於第 0 列和第 0 欄，只能代表其中一個：規定它只代表第 0 欄，第 0 列另外用 rowZero 記。

第一圈掃全部，做標記：
matrix[r][c] == 0 時：
matrix[0][c] = 0（欄標記）
r > 0 時 matrix[r][0] = 0（列標記），r == 0 時 rowZero = True。

第二圈只處理內部 r >= 1、c >= 1：
matrix[r][0] == 0 或 matrix[0][c] == 0 就清成 0。

最後依序處理標記區：
matrix[0][0] == 0 => 清第 0 欄
rowZero => 清第 0 列（一定要放最後）

踩過的坑：
用 ‘’ 當標記時，(0,0) 同時代表第 0 列和第 0 欄，看到 ‘’ 分不出是哪個要清，會把不該清的第 0 列清掉。清第 0 列時還會把第 0 列上的欄標記蓋掉，導致後面漏清整欄。為了過範例 2 加的 (0, COLS-1) 特例只是補丁，換一組測資就錯。

rowZero 宣告了卻沒有在第一圈設成 True，第 0 列原本有 0 時就永遠不會被清。

第二圈的 c 要從 1 開始，不能從 0 開始。從 0 開始的話，c=0 會因為 matrix[0][0]==0 先把 matrix[r][0] 改成 0，後面的格子讀到這個 0，就把整列誤清。標記要等用完才能動。

if r > 0 要保護的是 matrix[r][0]，不是 matrix[0][c]：
r == 0 時 matrix[r][0] 就是 matrix[0][0]，會汙染第 0 欄的標記，導致第 0 欄被誤清。
matrix[0][c] 在 r == 0 時寫的就是那格本身，本來就是 0，不用保護。

複雜度：
O(m * n) time / O(1) space
