**Count Commas**

**題目概述：**  
給一個整數 `n`，計算從 `1` 到 `n` 的所有數字中，總共會出現多少個逗號。題目範圍不需要考慮 `1,000,000` 以上的數字。

**解題邏輯：**  
`1 ~ 999` 都沒有逗號。

從 `1,000` 開始，每個數字都剛好有 `1` 個逗號，因此只要計算 `[1000, n]` 這個區間有多少個數字。

區間數量公式：

`n - 1000 + 1 = n - 999`

如果 `n < 1000`，答案就是 `0`。

所以可以直接：

`max(0, n - 999)`

不需要用 loop 一個一個檢查數字。

**時間複雜度：**  
`O(1)`

**空間複雜度：**  
`O(1)`

**踩過的坑：**  
無。
